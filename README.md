# go-homology

Exploring simplicial homology in Go: building chain complexes and computing topological invariants for fun.

Given a finite simplicial complex $K$, the program builds the integer matrices of its boundary operators, reduces them to Smith normal form and reads off the homology groups $H_k(K;\mathbb{Z})$, Betti numbers and torsion included. It uses only the Go standard library.

## Quick start

Requires Go 1.27.1 or newer (see [homology/go.mod](homology/go.mod)).

```bash
cd homology
go run .
```

The program computes the homology of the complexes defined in [homology/main.go](homology/main.go). For each one it prints the simplices grouped by dimension, followed by the homology groups:

```text
=== Borda de um triângulo (S¹) ===
Complexo:
Dimensão 0: [[1] [0] [2]]
Dimensão 1: [[0 1] [1 2] [0 2]]
Grupos de homologia:
  H_0 = Z
  H_1 = Z
```

Groups are printed as direct sums: `Z^2 + Z/2` means $\mathbb{Z}^2 \oplus \mathbb{Z}/2$, and `0` is the trivial group.

## Usage

The code is a single `main` package, so to try your own complex add a function to [homology/main.go](homology/main.go) and call it from `main`:

```go
func FigureEight() {
	c := NewComplex()
	// Two hollow triangles sharing vertex 0
	for _, e := range [][2]int{{0, 1}, {1, 2}, {2, 0}, {0, 3}, {3, 4}, {4, 0}} {
		c.Add(NewSimplex(e[0], e[1]))
	}
	for _, h := range ComputeHomology(c) {
		fmt.Printf("H_%d = %s\n", h.Dim, h)
	}
	// Output:
	// H_0 = Z
	// H_1 = Z^2
}
```

- `NewSimplex` sorts its vertices and removes duplicates, so `NewSimplex(2, 0, 1)` and `NewSimplex(0, 1, 2)` are the same simplex.
- `Add` inserts a simplex together with all of its faces, so you only need to list the maximal simplices.
- `ComputeHomology` returns one `HomologyGroup` per dimension $k = 0, \dots, \dim K$, with the Betti number in `FreeRank` and the torsion coefficients in `Torsion`.

## Theory

### Simplices and simplicial complexes

A $k$-simplex is the convex hull of $k+1$ affinely independent points. Combinatorially it is determined by its vertices, so we write it as $\sigma = [v_0, v_1, \dots, v_k]$. Vertices are 0-simplices, edges are 1-simplices, triangles are 2-simplices and tetrahedra are 3-simplices. A face of $\sigma$ is a simplex spanned by a nonempty subset of its vertices.

A finite simplicial complex $K$ is a finite set of simplices that is closed under taking faces: if $\sigma \in K$ and $\tau$ is a face of $\sigma$, then $\tau \in K$. We write $K_k$ for the set of $k$-simplices of $K$ and $n_k = \lvert K_k \rvert$ for their number.

In the code vertices are integers, `NewSimplex` stores them in increasing order, and `SimplicialComplex.Add` enforces the closure property.

### Chain groups

The group of $k$-chains is the free abelian group generated by the $k$-simplices:

$$
C_k(K) = \bigoplus_{\sigma \in K_k} \mathbb{Z}\,\sigma \cong \mathbb{Z}^{n_k}.
$$

A $k$-chain is a formal sum $c = \sum_i a_i \sigma_i$ with $a_i \in \mathbb{Z}$. Simplices are oriented: swapping two vertices flips the sign, for example $[v_1, v_0] = -[v_0, v_1]$. The code always takes the increasing order of the vertices as the positive orientation. `ChainGroup(k)` returns the ordered basis of $C_k$, and $C_k = 0$ for $k < 0$ and for $k > \dim K$.

### The boundary operator

The boundary of a $k$-simplex is the alternating sum of its $(k-1)$-faces,

$$
\partial_k [v_0, \dots, v_k] = \sum_{i=0}^{k} (-1)^i \, [v_0, \dots, \hat{v}_i, \dots, v_k],
$$

where $\hat{v}_i$ means that $v_i$ is omitted. This is extended linearly to a homomorphism $\partial_k : C_k \to C_{k-1}$. For example:

$$
\partial_1 [0,1] = [1] - [0], \qquad \partial_2 [0,1,2] = [1,2] - [0,2] + [0,1].
$$

The key property is that a boundary has no boundary:

$$
\partial_{k-1} \circ \partial_k = 0,
$$

because every $(k-2)$-face of $\sigma$ shows up twice, with opposite signs. For the triangle,

$$
\partial_1 \partial_2 [0,1,2] = \big([2]-[1]\big) - \big([2]-[0]\big) + \big([1]-[0]\big) = 0.
$$

The chain groups and boundary maps form the chain complex of $K$, with $n = \dim K$:

$$
0 \longrightarrow C_n \xrightarrow{\ \partial_n\ } C_{n-1} \xrightarrow{\ \partial_{n-1}\ } \cdots \xrightarrow{\ \partial_2\ } C_1 \xrightarrow{\ \partial_1\ } C_0 \xrightarrow{\ \partial_0\ } 0.
$$

`Simplex.Faces` returns the signed terms of the sum above, and `BoundaryMatrix(c, k)` assembles the $n_{k-1} \times n_k$ integer matrix of $\partial_k$, whose $j$-th column holds the coefficients of $\partial_k \sigma_j$.

### Cycles, boundaries and homology

The $k$-cycles are the chains with no boundary, and the $k$-boundaries are the chains that are the boundary of something:

$$
Z_k = \ker \partial_k, \qquad B_k = \operatorname{im} \partial_{k+1}.
$$

Since $\partial_k \circ \partial_{k+1} = 0$, every boundary is a cycle, so $B_k \subseteq Z_k$. The $k$-th homology group is the quotient

$$
H_k(K) = \frac{Z_k}{B_k} = \frac{\ker \partial_k}{\operatorname{im} \partial_{k+1}}.
$$

Intuitively, $H_k$ counts the $k$-dimensional cycles that do not bound anything: $H_0$ detects connected components, $H_1$ independent loops, and $H_2$ enclosed cavities.

$H_k(K)$ is a finitely generated abelian group, so by the structure theorem it has the form

$$
H_k(K) \cong \mathbb{Z}^{\beta_k} \oplus \mathbb{Z}/t_1 \oplus \cdots \oplus \mathbb{Z}/t_m, \qquad t_i > 1, \quad t_i \mid t_{i+1}.
$$

The rank $\beta_k$ is the $k$-th Betti number, and the $t_i$ are the torsion coefficients. `HomologyGroup` stores exactly this data: `FreeRank` is $\beta_k$ and `Torsion` is the list $(t_1, \dots, t_m)$.

### Smith normal form

For every integer matrix $A \in \mathbb{Z}^{m \times n}$ there are matrices $P \in GL_m(\mathbb{Z})$ and $Q \in GL_n(\mathbb{Z})$, that is, integer matrices with determinant $\pm 1$, such that

$$
PAQ = D = \operatorname{diag}(d_1, \dots, d_r, 0, \dots, 0), \qquad d_i > 0, \quad d_1 \mid d_2 \mid \cdots \mid d_r,
$$

where $r = \operatorname{rank} A$. The $d_i$ are the invariant factors of $A$ and they are unique. $P$ and $Q$ are products of the elementary operations that are invertible over $\mathbb{Z}$: swapping two rows (or columns), adding an integer multiple of one row (or column) to another, and multiplying a row (or column) by $-1$. Unlike over a field, dividing a row by a number is not allowed.

`MatrixInt.SmithNormalForm` works on the diagonal positions $t = 0, 1, 2, \dots$ in turn:

1. Find the nonzero entry of smallest absolute value among the rows and columns $\ge t$, and move it to position $(t,t)$ with a row swap and a column swap.
2. For every entry $a$ below the pivot $p$, subtract $q = a / p$ (integer division) times row $t$ from its row, which leaves the remainder $a - qp$ with $\lvert a - qp \rvert < \lvert p \rvert$. If the remainder is nonzero, that row becomes the new pivot row, and the step starts over. The same is then done with the columns to the right of the pivot. This is the Euclidean algorithm, run on rows and columns.
3. Once row $t$ and column $t$ are zero apart from the pivot, check that $p$ divides every entry of the remaining block. If some entry does not, add its row to row $t$ and go back to step 1. This guarantees $d_t \mid d_{t+1}$.
4. Move on to $t + 1$.

The absolute value of the pivot never grows, and every nonzero remainder becomes a pivot of strictly smaller absolute value, so the procedure terminates. The method returns the absolute values of the nonzero diagonal entries.

### From boundary matrices to homology

Let $r_k = \operatorname{rank} \partial_k$, the number of nonzero invariant factors of $\partial_k$, with $r_0 = 0$ and $r_{n+1} = 0$. By rank–nullity,

$$
\operatorname{rank} Z_k = n_k - r_k, \qquad \operatorname{rank} B_k = r_{k+1},
$$

so the Betti numbers are

$$
\beta_k = n_k - r_k - r_{k+1}.
$$

The torsion of $H_k$ comes from $\partial_{k+1}$, the map into $C_k$. If $d_1, \dots, d_{r_{k+1}}$ are the invariant factors of $\partial_{k+1}$, rewriting $C_{k+1}$ and $C_k$ in the bases given by $Q$ and $P^{-1}$ turns $\partial_{k+1}$ into $D$, so

$$
C_k / B_k \cong \mathbb{Z}^{\,n_k - r_{k+1}} \oplus \bigoplus_{i=1}^{r_{k+1}} \mathbb{Z}/d_i.
$$

The map $\partial_k$ induces a surjection $C_k / B_k \to B_{k-1}$ whose kernel is $Z_k / B_k = H_k$. Since $B_{k-1}$ is a subgroup of the free group $C_{k-1}$, it is free, so the short exact sequence

$$
0 \longrightarrow H_k \longrightarrow C_k / B_k \xrightarrow{\ \partial_k\ } B_{k-1} \longrightarrow 0
$$

splits and $C_k / B_k \cong H_k \oplus B_{k-1}$. Therefore $H_k$ has the same torsion as $C_k / B_k$. Invariant factors equal to $1$ contribute $\mathbb{Z}/1 = 0$, which gives

$$
H_k(K) \cong \mathbb{Z}^{\,n_k - r_k - r_{k+1}} \oplus \bigoplus_{d_i(\partial_{k+1}) > 1} \mathbb{Z}/d_i.
$$

In short, computing $H_k$ only takes the Smith normal forms of $\partial_k$ and $\partial_{k+1}$.

### Euler characteristic

The Euler characteristic can be computed either from the simplex counts or from the Betti numbers:

$$
\chi(K) = \sum_{k \ge 0} (-1)^k \, n_k = \sum_{k \ge 0} (-1)^k \, \beta_k.
$$

The second equality follows by substituting $\beta_k = n_k - r_k - r_{k+1}$: the $r_k$ terms cancel in the alternating sum. It is a handy sanity check. For the torus, $7 - 21 + 14 = 0 = 1 - 2 + 1$.

### Worked example: the circle

The boundary of a triangle has vertices $[0], [1], [2]$ and edges $[0,1], [1,2], [0,2]$. With rows indexed by vertices and columns by edges, in that order,

$$
\partial_1 =
\begin{pmatrix}
-1 & 0 & -1 \\
1 & -1 & 0 \\
0 & 1 & 1
\end{pmatrix}
\xrightarrow{\text{SNF}}
\begin{pmatrix}
1 & 0 & 0 \\
0 & 1 & 0 \\
0 & 0 & 0
\end{pmatrix}.
$$

So $r_1 = 2$ with no torsion, and $r_0 = r_2 = 0$. The Betti numbers are

$$
\beta_0 = 3 - 0 - 2 = 1, \qquad \beta_1 = 3 - 2 - 0 = 1,
$$

so $H_0 \cong \mathbb{Z}$ (one connected component) and $H_1 \cong \mathbb{Z}$, generated by the loop

$$
z = [0,1] + [1,2] - [0,2], \qquad \partial_1 z = \big([1]-[0]\big) + \big([2]-[1]\big) - \big([2]-[0]\big) = 0.
$$

Filling in the triangle (the `D2` example) adds the 2-simplex $[0,1,2]$ with $\partial_2 [0,1,2] = z$. Now $z$ is a boundary, so $r_2 = 1$ and $\beta_1 = 3 - 2 - 1 = 0$: the hole is gone.

### Where torsion comes from: the projective plane

In the 6-vertex triangulation of $\mathbb{RP}^2$ there is a loop $\gamma$ that is not the boundary of any 2-chain, while $2\gamma$ is. Its class therefore has order 2, and $H_1(\mathbb{RP}^2) \cong \mathbb{Z}/2$. In matrix terms, $\partial_2$ has rank $r_2 = 10$ and invariant factors $(1, \dots, 1, 2)$: nine 1s and a single 2. With $n_1 = 15$ and $r_1 = 5$, the Betti number is $\beta_1 = 15 - 5 - 10 = 0$, so $H_1$ is pure torsion. Since $\partial_2$ is injective, $H_2 = \ker \partial_2 = 0$. Rational or $\mathbb{Z}/p$ coefficients with $p$ odd cannot see this class at all, which is why the computation is done over $\mathbb{Z}$.

## Limitations

- Matrices are dense `[][]int`, so memory grows as $n_{k-1} \cdot n_k$ and the Smith normal form takes roughly cubic time. That is fine for small, hand-built complexes but not for large ones.
- Entries can grow during elimination, and `int` arithmetic is not checked for overflow.
- Coefficients are always $\mathbb{Z}$. There is no option for field coefficients such as $\mathbb{Q}$ or $\mathbb{Z}/2$.
- `SmithNormalForm` modifies its matrix in place.
